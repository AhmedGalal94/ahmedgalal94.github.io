# 🏛️  Developer Portfolio 

A clean, responsive, and SEO-optimized developer portfolio built to showcase high-scale enterprise systems, cloud topologies, and backend proficiencies. 

This portfolio is fully open-source. Feel free to fork it, customize it, and use it to showcase your own engineering journey.

Live Demo: [https://ahmedgalal94.github.io](https://ahmedgalal94.github.io)

---

## 🛠️ Tech Stack

- **Frontend & Layout:** Semantic HTML5, CSS3 Custom Properties (Variables), and lightweight JavaScript.
- **Dual-Language Engine:** Built-in localization support (`data-en` and `data-ar` attributes) for clean English/Arabic contextual toggle switching.
- **SEO & Discoverability:** Configured with Schema.org Microdata schemas (`SoftwareApplication`, `CreativeWork`) to map projects seamlessly to search crawlers.
- **Hosting & Deployment:** Automatically built and served via **GitHub Pages**.

---

## 🚀 How to Customize This Portfolio for Yourself

### 1. Fork and Clone the Repository
Click the **Fork** button at the top right of this page, then clone your fork locally:
```bash
git clone https://YOUR_USERNAME.github.com
cd YOUR_USERNAME.github.io
```

### 2. Rename the Repository
To host it on GitHub Pages for free under your own name, navigate to your repository **Settings** and rename it to match your exact GitHub handle:
`YOUR_USERNAME.github.io`

### 3. Update the Portfolio Content
Open `index.html` and modify the fields to match your personal specifications:
- Change the core meta tags in the `<head>` to point to your LinkedIn profile and name.
- Customize the `#projects` container cards with your own enterprise products, image assets, and tags.
- Update the **Core Engineering Proficiencies** skill matrix meters.
